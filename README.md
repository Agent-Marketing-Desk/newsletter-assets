# Agent Marketing Desk — Newsletter Assets

Public CDN-style mirror of image assets used by the AMD weekly newsletter. The newsletter source — brand guide, templates, content, generator — lives in a private repo. This repo exists so that recipients' email clients can fetch images via `raw.githubusercontent.com`.

If you found this repo through a newsletter image URL: hi 👋. The actual newsletter goes out weekly via Brevo and you can subscribe at [agentmarketingdesk.com](https://agentmarketingdesk.com).

## Structure

```
assets/
├── brand/      ← AMD logo variants
├── team/       ← Team headshots (also visible on agentmarketingdesk.com/pages/about-us)
└── products/   ← Product imagery for permanent newsletter sections
2026/
└── MM-month/
    └── YYYY-MM-DD/
        └── assets/images/   ← Per-issue images (issue archive)
```
